# GDデモ

グループディスカッション（GD）未経験の学生向けに、模範的なGDの流れを約2〜3分のアニメーションで見られるWebアプリです。

公開URL: https://gd-demo-33a.pages.dev/

- GDの型（ビジネス型・課題解決型・抽象テーマ型・フェルミ推定型・選択/ディベート型）× お題3つ = 15本
- 5人（司会・タイムキーパー・書記・発表者・メンバー）が、役割決めから発表までを吹き出しで進める
- 役割としての発言は太字で強調。重要な場面では背景が役割のイメージカラーに変わり、「なぜ今それを言うのが大事か」の解説が出る
- 台本は事前に用意した固定データなので、待ち時間なしで再生できる
- ログイン不要。リンクを開けば誰でも見られる

## 操作

| 画面 | 操作 |
| --- | --- |
| ホーム | 型カードを左右にフリックで切り替え、お題をタップ |
| お題シート | 上フリック or「デモを見る」で開始／下フリックで閉じる |
| デモ | 左右フリックで発言送り・戻し、人物の列をタップで一時停止、速度 ×1 / ×1.5 / ×2、書記のボード |
| 重要場面 | 解説を読んだら「続きを見る」（または左フリック） |

## 台本

- `src/scripts/<お題ID>.ts` に1お題1ファイル
- 書き方の基準は [docs/gd-guide.md](docs/gd-guide.md)
- `npm test` で台本のルール（フェーズ順・役割決め・重要場面の数など）も検査する

## 技術構成

| 領域 | 採用技術 |
| --- | --- |
| フロントエンド | React 19 + TypeScript + Vite |
| アニメーション・ジェスチャー | Motion（旧 Framer Motion）＋ CSS アニメーション |
| ホスティング | Cloudflare Pages |
| テスト | Playwright（iPhone 13 相当の画面で E2E） |
